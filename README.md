# Automora AI

> AI that actually runs your business.

Automora is an AI Business Operator for small businesses.

## Core Idea

Tell Automora what needs to happen. It does it.

## Core Demo

"Book Rahul tomorrow at 5 PM."

Automora:
1. Finds Rahul
2. Checks availability
3. Creates the booking
4. Generates confirmation
5. Schedules a reminder

## Tech Stack

- React Native + Expo
- TypeScript
- Supabase
- OpenAI API
- RevenueCat
